# Image sources

The Hanoi emblem and service shortcut graphics in this directory were copied from the public homepage of the Hanoi Public Administration Service Center, which currently uses these images in its public information pages:

- Source page: https://ttpvhcc.hanoi.gov.vn/trang-chu
- Image host: https://storage-vnportal.vnpt.vn/gov-hni/6810/
- Files: `hanoi-logo.png`, `nophoso.png`, `tracuuhoso1cua.png`, `tracuuketquagiaiquyethoso.png`, `thanhtoantructuyen.png`, and `congdichvucongquocgia.png`.
- The printed labels in the source graphics are authoritative: `nophoso.png` says “Nộp hồ sơ”; `tracuuhoso1cua.png` says “Tra cứu tình trạng hồ sơ”; `tracuuthutuchanhchinh.png` says “Thanh toán trực tuyến”; `tracuuketquagiaiquyethoso.png` says “Đánh giá trực tuyến”; and `thanhtoantructuyen.png` is a wide “Thanh toán trực tuyến” banner. The homepage uses the first two only where their printed labels match; procedure search and the guide use neutral symbols so a payment/evaluation image is not misrepresented.

The citizen support photo is from the Center's article “Nụ cười của người dân là hạnh phúc của tổ lưu động số”:

- Source page: https://ttpvhcc.hanoi.gov.vn/hoat-dong-cua-trung-tam/nu-cuoi-cua-nguoi-dan-la-hanh-phuc-cua-to-luu-dong-so-2850260420111907282.htm
- Original image: https://sqhx-hanoi.mediacdn.vn/thumb_w/740/91579363132710912/2026/4/20/picture1-17766544808961527675614.jpg
- File: `citizen-support.jpg`.

The Center's website requests that material be credited to “Trang thông tin điện tử Trung tâm Phục vụ hành chính công thành phố Hà Nội” when republished. The page captions and this source list provide that attribution. These assets are used as public visual references in this locally developed system.
